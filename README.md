# 免备案VPS：按用户所在地选机房，DMIT 全套餐与当前价格一次看懂

“免备案VPS”真正要解决的问题，通常不是单纯找一台境外服务器，而是同时满足几个条件：**不用走大陆机房的 ICP 备案流程、上线快、访问目标地区稳定、配置够用，而且价格别因为一条所谓“优化线路”突然翻几倍**。

这也是为什么选 VPS 时，机房位置和线路往往比“CPU 几核、内存几 GB”更值得先看。面向中国大陆用户，香港、洛杉矶、东京的实际访问路径差别很大；面向欧美客户时，反而没必要为中国优化线路额外付钱。

这篇文章把这些问题拆开说，并把目前 DMIT Pricing 页面公开展示的套餐完整整理出来。本文价格以本次检索时官网公开页面为准，DMIT 官方同时提醒产品和价格可能因为调整而存在更新延迟，所以实际下单时仍应以结算页显示为准。

## 先弄清楚：免备案VPS到底“免”的是什么

通常大家说的“免备案 VPS”，指的是把服务器部署在中国大陆以外的数据中心，因此不需要把它当作大陆机房网站那样走对应的 ICP 备案流程。

但“境外服务器”并不等于“所有事情都自动免备案、免监管”。工信部现行《非经营性互联网信息服务备案管理办法》明确规定，在中华人民共和国境内提供非经营性互联网信息服务需要依法履行备案手续。换句话说，是否需要备案不能只看“服务器是不是海外”，还要看业务的实际提供方式、接入方式和适用的法律要求。

所以，免备案 VPS 更适合这些需求：

* 海外用户为主的企业站、博客、SaaS、API；
* 外贸独立站、跨境电商项目；
* 需要快速上线的测试环境、开发环境；
* 不希望把网站直接部署在大陆机房的项目；
* 面向中国大陆，但希望采用香港、日本或美国境外节点的服务。

这里还有一个容易忽略的问题：**“免备案”解决的是部署门槛，不会自动解决访问速度。**

香港服务器可以离大陆用户很近，美国服务器可以对北美客户更近，但两者面对同一批中国大陆访问者时，网络路径完全不同。DMIT 目前就在洛杉矶、香港、东京提供 Cloud Instance，且不同节点又拆成 Premium、Eyeball、Tier 1 三类网络。

## 选免备案VPS，先按“用户在哪里”决定机房

### 面向中国大陆：先看香港，再看线路

DMIT 香港节点位于 Equinix HK2。官网给出的参考数据是香港到中国大陆约 **15ms**，参考测量点为香港到深圳，同时注明实际延迟会受到运营商、路由和时间影响。Premium Network 使用 CN2 GIA，官方公开的参考数据还包括低于 0.1% 的峰值丢包指标，但同样不是所有用户、所有线路下的固定保证。

这类节点适合：

* 中国大陆用户占比较高的网站；
* API、后台管理系统；
* 对交互延迟比较敏感的服务；
* 香港 IP 或亚太区域部署需求。

代价也很直观：香港套餐价格通常比普通美国 Tier 1 VPS 高不少。

### 面向北美用户：洛杉矶通常更自然

如果网站主要面向美国、加拿大或拉美用户，把服务器放在洛杉矶往往更符合访问路径。

DMIT 当前洛杉矶节点强调的是北美与亚太之间的连接能力。官网还区分了 Premium、Eyeball 和 Tier 1：Premium 面向需要中国大陆优化路由的业务；Eyeball 是折中方案；Tier 1 则更偏向普通国际网络和跨区域带宽，不针对中国大陆做专门优化。

这意味着一个很简单的判断：

> 如果你的客户根本不在中国大陆，就不要为了“CN2”三个字自动多花钱。

对于外贸站、欧美 API、海外 SaaS 或备份节点，普通 Tier 1 方案完全可能更符合需求。

### 面向日本、韩国及东亚：东京是另一条路线

DMIT 东京节点目前采用 AMD EPYC 7003 系列，提供 Premium 和 Tier 1 网络。官网给出的中国大陆参考延迟约 **28ms**，同样明确说明实际数据会随线路和时间变化。

因此东京更适合：

* 日本市场网站；
* 日本、韩国及东亚用户；
* 亚太跨区域 API；
* 对日本节点 IP 有实际需求的项目。

如果你的主要访客就在日本，单纯为了大陆访问去比较美国线路，方向本身就已经偏了。

## DMIT 的三种网络，差别比套餐名字更值得看

DMIT 当前把网络分成三档。

**Premium Network** 针对中国大陆和亚太访问，使用包括 CN2 GIA 在内的优化路径。官网给出的描述是更低延迟、更少跳数和更低丢包。

**Eyeball Network** 是折中方案。官方称其通过 CMIN2 等中国用户侧网络提供“reasonable-effort”式的中国方向优化，成本低于 Premium，但不提供同级别的路由保证。洛杉矶节点还把它明确定位在中国/全球混合用户、API 和 SaaS 等场景。

**Tier 1 Network** 则重点放在亚太、北美、欧洲之间的国际连接，不针对中国大陆提供专门优化。对于海外用户为主的业务，这反而可能是更合理的路线。

这三类网络不要只理解成“贵、中、便宜”。更准确的理解是：

**Premium 买的是中国大陆方向的网络质量，Eyeball 买的是折中，Tier 1 买的是普通国际网络与带宽。**

## 看起来便宜的套餐，为什么不一定适合做网站

拿 LAX.AS3.T1 的 TINY 来说，**$6.90/月**确实足够低，WEE 甚至直接显示 **$36.90/年**。但它是 Tier 1 路线，本身没有中国大陆优化，而且 AS3 还存在官网明确提示的平台建设状态。

如果你的博客访问者主要来自中国大陆，那么单纯因为 $6.90 很便宜就选它，很可能是在拿“机器便宜”换“网络不确定性”。

反过来，如果你的客户主要在美国，网站只是给自己偶尔登录后台，那么花更多钱上中国优化线路，也可能是没有必要的成本。

因此购买时应该先问：

**用户在哪里？**

再问：

**需要中国大陆优化吗？**

最后才是：

**我需要多少 CPU、内存和磁盘？**

顺序反过来，很容易把预算花在不重要的指标上。

## “免备案VPS”最常见的几个实际场景

### 外贸独立站

如果客户主要在美国、欧洲，那么洛杉矶的 Tier 1 或普通国际路线往往比针对中国的 Premium 更符合访问路径。

这类项目真正该看的是：CPU 是否够用、SSD 是否够、流量是否够、带宽上限是多少，以及是否有需要额外购买备份或快照。

### 中国大陆访问为主的网站

这时候机房位置和线路权重明显上升。

香港离大陆更近，DMIT 官方给出的参考延迟约 15ms；东京约 28ms；洛杉矶则属于跨太平洋路径。

如果业务的关键操作就是中国大陆用户频繁访问，应该优先看 Premium 或至少认真比较 Eyeball，而不是只看最低月付价格。

### 开发测试、临时项目

这类需求反而适合便宜套餐。

例如 LAX.AS3.T1 的 TINY 是 $6.90/月，WEE 是 $36.90/年；东京 Tier 1 也有同样的低价入口。

测试环境最重要的问题通常不是“能不能跑满 10Gbps”，而是项目能否稳定启动、SSH 是否顺手、磁盘是否足够、流量是否够用。

### API、SaaS 和后台系统

这类项目对线路稳定性和 CPU 单核响应更敏感。

DMIT 官方把 Premium、Eyeball 和 Tier 1 分得很清楚；洛杉矶页面还直接把 API backend、SaaS、远程开发等场景归到 Eyeball 的推荐范围。

所以不要把“网站”当成一种统一需求。一个主要给中国用户使用的 API，和一个服务美国客户的 SaaS，选 VPS 的逻辑完全不同。

## 第三方评价怎么看？

目前能查到的第三方测评，关注点高度集中在 DMIT 的网络，而不是“机器参数堆得有多高”。
